# Egypt Macroeconomic Indicators Analysis

## 1. Project Overview
This project analyses the development of Egypt's macroeconomic indicators between 2014 and 2024 using Python.

## 2. Project Objectives
- Analyse GDP growth trends.
- Examine inflation developments.
- Explore unemployment trends.
- Identify statistical relationships between the selected indicators.

## 3. Data Sources
World Bank – World Development Indicators (WDI).

Data is retrieved through the World Bank API.

## 4. Tools and Libraries
- Python
- Pandas
- NumPy
- Requests
- Matplotlib
- Seaborn
